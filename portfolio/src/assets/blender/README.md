# Blender renders

Drop images in this folder and they show up in the "Learning Blender" section on the home page.
No code changes needed. While the folder has no images, the section and its nav link stay hidden.

- Formats: `.png`, `.jpg`, `.jpeg`, `.webp`, `.avif`
- The caption comes from the file name: `02-low-poly-house.png` becomes "Low poly house"
- Order is alphabetical, so prefix with numbers (`01-`, `02-`, ...) to control it
- Keep files under ~1MB each (export at 1920px wide, or save as WebP)
